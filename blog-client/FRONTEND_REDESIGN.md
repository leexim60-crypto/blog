# 前端页面优化

这次优化围绕深墨色、薄荷绿和更舒适的阅读排版，覆盖首页、日记列表、详情、编辑器、登录注册与移动端导航。

- 首页使用 SVG 轨道插画，移除持续运行的首屏 Canvas 动画；保留每日壁纸切换。
- 作品直接展示在首页，支持游戏 / 工具筛选。导航跳转到作品区，不再挂载项目侧边栏。
- 日记列表提供清晰的月份层次，详情支持调整字号。搜索忽略过期响应，加载更多失败后重试同一页。
- 登录和移动导航支持键盘焦点管理。动效遵循系统的减少动画设置。
- 音乐是全站共享播放器，切换页面不会停止；不会自动播放。小挂件仍然可以按需打开，默认只显示时钟、一言和日历。

## 音源与播放器

网易云热歌、新歌、飙升、原创榜，以及自定义网易云歌单链接 / ID；另有 SoundHelix 器乐音源、HTTPS 音频直链与本地音频文件。

播放器支持歌曲 / 歌手搜索、歌单选择、收藏、列表 / 单曲 / 随机播放、进度拖动、音量和静音。媒体控制在支持的浏览器中接入系统的播放控件。

音源接口默认为 GD 音乐台。可以通过 `VITE_MUSIC_API_URL` 配置兼容接口地址，需要支持 `types=playlist/search/url` 的 GD API 格式。音源配置在 `src/stores/music.js` 的 `MUSIC_SOURCES` 中，作品信息在 `src/stores/projects.js` 中。

曲目播放地址按需获取，不持久化过期直链。音源故障时显示明确的重试 / 切源入口。平台曲目是否可播放仍受提供方的版权、地区、接口与网络状态影响。

自定义直链保存在当前浏览器。本地文件通过 Object URL 播放，不上传；刷新页面后需要重新选择。MP3 / M4A / WAV / OGG / FLAC 等格式的实际支持取决于浏览器。

## 验证

- Vite 生产构建通过。
- 21 项浏览器检查通过：作品筛选、搜索响应顺序、加载更多重试、阅读字号、模拟登录、Markdown 预览、播放器异步切歌 / 收藏 / 跨页面播放、自选歌单、本地音频 / 直链、失效切源，以及 375 / 390 / 768 / 1024 / 1920px 布局与移动导航。
- 交互检查使用隔离的测试数据与音频；没有向真实后端写入日记或账户。
- 真实网易云与 SoundHelix 音频探测均返回 HTTP 206 和 `audio/mpeg`。

在 `blog-client` 目录执行 `npm run dev` 查看页面，执行 `npm run build` 构建。
